# Shopify Sales & Customer Analytics

This folder contains the Power BI dashboard developed to analyse Shopify's e-commerce sales and customer performance.

The dashboard provides insights into revenue trends, customer behaviour, repeat purchases, product performance, geographical sales distribution and payment methods.

### Key Analysis
- Sales and revenue performance
- Customer retention and lifetime value
- Product and category performance
- Geographic sales distribution
- Payment gateway analysis
- Sales trends and peak hours

### Tools Used
Microsoft Power BI, Power Query, DAX and Data Modelling.

**Project Category:** Data Analytics | Business Intelligence
